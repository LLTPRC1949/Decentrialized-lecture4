Contract setup

Connect a Sepolia wallet and deploy a new ProofMark contract, or enter an existing address. Deployment uses Sepolia test ETH for gas. To configure the site for every visitor, set the resulting address in public/config.js and redeploy to Render.

On your phone

Open this website inside your mobile wallet’s browser to connect and register. File hashing also works in a regular mobile browser.

What does this prove?

A wallet recorded this fingerprint at a block timestamp. It does not prove copyright, authorship, or the file’s original creation time.

Testnet only

Registration uses Sepolia test ETH for gas. Verification reads the chain and does not send a transaction.
